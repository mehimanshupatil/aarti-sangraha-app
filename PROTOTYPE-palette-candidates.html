Palette candidates — collapsing 8 themes into one light/dark theme

Resolving Design the collapsed light/dark palette (Warm Parchment anchor, WCAG AA). Three candidates, each shown as light + dark side by side, applied to the app's actual surfaces: header, aarti list with deity tags, a reading view (the long devotional text block this app exists for), and the two real spots that currently render accent as text (Settings → “Reset customised data”, the aarti-view menu label) — the one pair that fails AA in the current Warm Parchment theme at 2.17:1.

Closest to today's default. Every value from the current "Warm Parchment" theme is kept exactly — primary #A03D0F, background #FAF4E8, surface #F3EAD5, border #C4A47A unchanged in light; the dark side is untouched too. The only change anywhere is accent in light mode, deepened from #D4A017 (2.17:1, fails) to #805C07 (5.55:1) so it's usable as text, not just decoration.
